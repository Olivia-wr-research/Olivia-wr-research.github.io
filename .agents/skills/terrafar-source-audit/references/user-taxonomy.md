## 五、地理学不能只使用 Geography 一个关键词

建议将学科关键词分成八组并行检索，否则会漏掉相当多跨学科项目。

| 学科方向     | 核心检索词                                                                   |
| -------- | ----------------------------------------------------------------------- |
| 人文地理     | Human Geography、Economic Geography、Social Geography、Political Geography |
| 城市与区域研究  | Urban Studies、Regional Studies、Urban Planning、Spatial Planning          |
| 空间与地理信息  | GIS、Geoinformatics、Geospatial Science、Spatial Data Science              |
| 遥感与地球观测  | Remote Sensing、Earth Observation、Geodesy、Geomatics                      |
| 自然地理     | Physical Geography、Hydrology、Geomorphology、Biogeography                 |
| 环境与气候    | Climate Science、Environmental Science、Sustainability、Climate Adaptation |
| 人口、交通与流动 | Population Geography、Demography、Transport Geography、Human Mobility      |
| 地理交叉研究   | Spatial Economics、Regional Innovation、Urban Analytics、Complex Systems   |

同时增加语言层面的检索词：

| 语言   | 重要关键词举例                                                     |
| ---- | ----------------------------------------------------------- |
| 中文   | 地理学、自然地理、人文地理、科研助理、博士后、教师招聘                                 |
| 德语   | Geographie、Doktorand、Wissenschaftlicher Mitarbeiter、Postdoc |
| 法语   | Géographie、Doctorat、Postdoctorat、Chargé de recherche        |
| 西班牙语 | Geografía、Doctorado、Investigador、Profesor                   |
| 葡萄牙语 | Geografia、Mestrado、Doutorado、Pós-doutorado                  |
| 日语   | 地理学、博士課程、研究員、助教、特任研究員                                       |
| 韩语   | 지리학、박사、박사후연구원、연구원                                           |

这不是简单的翻译问题。例如，德国的 `Wissenschaftlicher Mitarbeiter` 可以覆盖博士研究人员或其他学术雇员；法国的 `Chargé de recherche` 则通常属于不同的科研职业体系。不能仅根据词语相似性自动认定岗位学历级别。
