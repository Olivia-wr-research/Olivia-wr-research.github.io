方法与数据

数据系统

科学家流动数据

该数据系统将生物医药高被引科学家与机构、城市、职业阶段、流动事件、共同作者记录和论文地点字段连接起来，用于开展流动网络、职业嵌入、目的地选择与区域创新研究。

企业创新数据

该数据系统将全球高研发投入企业组织为企业年度观测，整合研发支出、专利、商标、行业、国家、企业身份和年份信息，用于分析技术导向创新与市场导向创新。

支撑性空间与政策数据

支撑性数据包括 VIIRS-DNB 夜间灯光、UN Comtrade、地理空间与城市属性数据，以及政策和规划文本。这些材料服务于空间测量、网络比较和政策解释。

数据构建与测量

职业、机构与城市重建

职业履历重建需要进行人员校验、机构标准化、城市标准化、时间审计，并审慎处理教育和任职记录，使个体职业轨迹能够在机构和城市之间进行纵向比较。

关系与空间测量

流动事件与城市属性、共同作者关系、全域网络指标、自我网络指标、地理邻近、认知邻近和候选目的地集合相连接。论文地点仅作为数据库字段处理，不被直接解释为已经验证的人际关系。

企业创新测量

企业层面测量将研发投入、专利和商标活动连接起来，协调不同来源中的企业身份，并组织为企业年度面板。目标是在不把创新简化为单一指标的前提下描述企业创新组合。

高频空间指标

遥感研究通过夜间灯光预处理、空间聚合、费舍尔信息和轨迹比较，从高频空间数据中构建城市韧性测度。

实证设计与模型

目的地选择设计

观察到的流动被组织为事件层面的选择集合：每次流动包含一个实际目的地和若干候选城市。解释变量在流动发生前测量，以保证时间顺序与关系暴露解释相一致。

网络与关系模型

网络分析用于描述有向赋权流动联系、核心结构、中心性、全域网络形成和科学家层面的自我网络。加权网络模型和邻近性测量支持从结构描述推进到关系解释。

计量与比较设计

实证研究使用事件分层条件 Logit、稳健性检验、敏感性分析、纵向比较和比较研究设计。早期定量训练还包括 Lasso、随机森林、支持向量机和交叉验证等应用建模方法。

空间与时间分析

当研究问题涉及空间测量或轨迹分析时，使用地理信息系统、动态时间规整、K-Means 聚类、空间聚合和时间比较等方法。

可复现研究与研究软件

可复现流程

研究流程强调脚本化处理、版本控制、数据质量审计、敏感性检查、合成测试样例，以及公开材料与受限数据的分离。这对纵向人才流动数据和授权书目来源数据尤为重要。

研究软件环境

常用环境包括 Python、R、Stata、地理信息系统软件、NetworkX、Gephi、Ucinet、Git、GitHub 和 Quarto。工具选择服务于数据构建、模型估计、文档生成和可复现发布。

书目数据处理工具

Scopus 研究数据工具包是用于 Scopus 来源研究数据流程中作者—机构—城市连接的开源 Python 工具。该工具使用合成测试样例、离线模拟传输、自动化测试和公开文档，不包含受限 Scopus 数据。
