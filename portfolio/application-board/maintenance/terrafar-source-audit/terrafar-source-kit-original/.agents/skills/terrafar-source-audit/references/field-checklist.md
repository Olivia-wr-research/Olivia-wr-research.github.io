# 核验清单与证据等级

事实字段最小证据：原URL + 短摘录/定位 + 实际抓取时间 + 内容SHA256。字段未知保留空值与原因。

| 核验对象 | 通过条件 | 不通过时 |
|---|---|---|
| 目标页面 | 页面确为配置的招生/招聘列表或正式公告 | needs_endpoint / failed / blocked |
| 翻页范围 | 必需页面与查询全部完成，终止理由有记录 | partial |
| 空结果 | 正确目标明确显示空结果，不是解析器空返回 | failed / partial |
| 原始机构 | 正式机构页面或经证据核对的委托招聘入口 | pending_review |
| 职位身份 | 职位编号/项目/角色能够区分，而非只看标题 | pending_review |
| 截止时间 | 原文日期、精度、时区、滚动条件分开保存 | 未知，不猜 |
| 资助 | 原文明确工资、津贴或学费安排 | 未知，不猜 |
| 当前状态 | 公告与申请途径没有已截止/取消/暂停冲突 | pending_review / closed |
| 出版资格 | 仅候选通过字段与状态核验且原格式校验通过 | 不进入正式发布 |

官方内容与申请入口互相矛盾时保留两条证据；页面年龄、已过期日期、旧学年都必须核对。严禁用今天的导入时间替代原发布日期或真实核验时间。

HTTP可达性、完整列表检查、详情有效性是三个不同指标。列表访问成功不自动刷新所有详情的last_verified_at。

人工审核是某个真人实际看过并确认；没有真人参与就不得写human_reviewed=true。
