# 全球地理学硕士、博士、博士后、教职及科研助理招聘信息源总目录

整理基准：2026年10月19日｜覆盖全球六大洲｜兼顾招生项目、带薪科研岗位和学术招聘

全球地理学相关机会不能只依靠几个国际学术招聘网站。要实现尽可能完整的覆盖，需要建立一个全球平台＋国家招聘系统＋学科专业平台＋大学及科研机构官网的多层信息源体系。

尤其需要区分两种发布机制：

- 招生型：硕士、普通博士主要通过大学招生门户、研究生院和奖学金系统发布。
- 招聘型：带薪博士、博士后、科研助理和教职通常通过学校人事系统、科研机构招聘页面及学术职位平台发布。

这两种机制有交叉，但不能混为一谈。一个只抓取学术招聘网站的系统，会系统性遗漏大量硕士和博士招生信息。

## 五、地理学不能只使用 Geography 一个关键词

建议将学科关键词分成八组并行检索，否则会漏掉相当多跨学科项目。

| 学科方向     | 核心检索词                                                                   |
| -------- | ----------------------------------------------------------------------- |
| 人文地理     | Human Geography、Economic Geography、Social Geography、Political Geography |
| 城市与区域研究  | Urban Studies、Regional Studies、Urban Planning、Spatial Planning          |
| 空间与地理信息  | GIS、Geoinformatics、Geospatial Science、Spatial Data Science              |
| 遥感与地球观测  | Remote Sensing、Earth Observation、Geodesy、Geomatics                      |
| 自然地理     | Physical Geography、Hydrology、Geomorphology、Biogeography                 |
| 环境与气候    | Climate Science、Environmental Science、Sustainability、Climate Adaptation |
| 人口、交通与流动 | Population Geography、Demography、Transport Geography、Human Mobility      |
| 地理交叉研究   | Spatial Economics、Regional Innovation、Urban Analytics、Complex Systems   |

同时增加语言层面的检索词：

| 语言   | 重要关键词举例                                                     |
| ---- | ----------------------------------------------------------- |
| 中文   | 地理学、自然地理、人文地理、科研助理、博士后、教师招聘                                 |
| 德语   | Geographie、Doktorand、Wissenschaftlicher Mitarbeiter、Postdoc |
| 法语   | Géographie、Doctorat、Postdoctorat、Chargé de recherche        |
| 西班牙语 | Geografía、Doctorado、Investigador、Profesor                   |
| 葡萄牙语 | Geografia、Mestrado、Doutorado、Pós-doutorado                  |

## 六、为了全球覆盖，还必须补充大学与科研机构官网

前面的列表主要解决“去哪儿发现机会”。但如果最终目的是尽可能全面地汇总全球地理学机会，还需要维护机构级来源。

我建议按以下结构扩展：

四级信息源体系：聚合平台用于发现，机构官方公告用于最终确认。

优先纳入的机构类型包括：

- 大学地理学系及相邻院系：地理学、地球科学、城市规划、环境科学、区域经济、空间数据科学。
- 国家科研机构：德国马克斯·普朗克学会、法国 CNRS、日本理化学研究所、韩国基础科学研究院、澳大利亚联邦科学与工业研究组织等。
- 专题研究中心：气候研究中心、人口研究中心、城市研究所、遥感实验室、交通研究中心、区域创新研究中心。
- 研究资助机构：英国研究与创新署、德国研究基金会、瑞士国家科学基金会、欧洲研究理事会等。它们主要用于发现资助项目或奖学金，不应一律当作职位招聘平台。

## 七、如果建立全球地理学招聘数据库，如何组织数据？

这一步直接影响后续能不能有效搜索、去重和更新。

建议至少建立以下字段：

| 数据字段                          | 说明                |
| ----------------------------- | ----------------- |
| `opportunity_id`              | 内部唯一编号            |
| `source_name` / `source_url`  | 来源网站及页面           |
| `official_url`                | 学校或机构的原始招聘公告      |
| `application_url`             | 正式申请入口            |
| `country` / `institution`     | 国家、学校或研究机构        |
| `opportunity_type`            | 硕士、博士、博士后、教职、科研助理 |
| `discipline`                  | 规范化学科类别           |
| `title_original` / `title_en` | 原始职位名称、英文标准化名称    |
| `funding_status`              | 全额资助、部分资助、自费、未知   |
| `employment_type`             | 雇佣岗位、奖学金、招生项目     |
| `salary` / `tuition`          | 薪酬、津贴或学费          |
| `eligibility`                 | 学历、语言、国籍等申请资格     |
| `posted_date` / `deadline`    | 发布日期和申请截止日期       |
| `last_verified_at`            | 最后一次核验时间          |
| `status`                      | 招聘中、已截止、取消、待核实    |
| `verification_level`          | 聚合信息、官方公告、申请入口已核实 |

尤其需要建立岗位去重机制。同一个职位可能同时出现在 EURAXESS、Academic Positions、jobs.ac.uk 和学校官网。不能简单根据职位标题去重，因为同一实验室可能同时招聘多名研究人员。

更可靠的组合是：发布机构、职位编号、项目名称、申请链接和截止日期。

### 一个需要特别避免的问题

信息源覆盖率不等于职位覆盖率。

即使接入100个网站，也无法据此声称覆盖了全球90%的地理学招聘。要验证覆盖能力，应选取不同国家、机构和岗位类型作为测试样本，比较真实公开职位中有多少被系统发现。

因此，当前这份目录是全球多地区的首版信息源清单，不是经过逐国穷尽审计的全球完整名录。除已经明确核实的招聘功能外，部分国家级门户和学校首页还需要继续定位其具体招生、招聘栏目。

## 八、推荐的建设优先顺序

第一批：核心来源

优先上线

EURAXESS、jobs.ac.uk、AcademicTransfer、FindAPhD、FindAMasters、AAG、RSA、HigherEdJobs、JREC-IN、University Affairs、Academic Positions。

第二批：国家级信息源

德国、法国、中国、瑞典、挪威、加拿大、澳大利亚、巴西、阿根廷、韩国及新加坡的官方招聘和科研系统。

第三批：机构级全覆盖

以全球设有地理学及相关学科的大学、科学院和研究机构为基础，逐一补充人事招聘、研究生招生、奖学金及实验室页面。

第四批：补漏与质量验证

增加非洲、拉丁美洲、中东和东南亚本地语言来源；抽样检测遗漏率、职位时效性、重复率和官方申请链接有效性。

我的结论是：真正有价值的全球地理学机会库，不是简单收集几百个网站，而是把分散的招生和招聘机制统一起来，并能追溯到每一条原始公告。

这一版已经列出全球主要区域的核心平台、国家入口、大学和科研机构网站。后续要做到更完整，应继续扩展为“国家—机构—院系—信息页面”的结构化来源库，尤其补齐非英语国家的信息。
