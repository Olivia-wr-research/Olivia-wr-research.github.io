# 下一站 · 发现岗位＋理解匹配

[直接使用](https://olivia-wr-research.github.io/apps/application-board/) · [匹配规则与数据说明](docs/MATCHING.md)

这次不再把申请进度面板当成岗位雷达：首页已重做为中文岗位发现页，支持国家、领域、截止日期筛选，个人兴趣／方法匹配、可解释的分项理由、资格待核验项、收藏与申请清单衔接。原来的材料与进度管理仍在 `tracker.html`，既有记录不会因升级被覆盖。

## 匹配机制

填写概括性兴趣和方法即可，不用上传 CV。关键词重合按兴趣 70%、方法 30% 计算；只填一项时按该项归一化。地区偏好、学历和英语条件独立展示，不用兴趣高分抵消条件缺口。

它是透明的小型词表匹配，不是大模型语义理解，不是录取概率，不判断你最终是否符合岗位资格；没有档案不编造分数。未命中也不等于不适合。

## 数据边界

首批只有 6 条、2 个国家的官方雇主页面快照，核对日期为 2026-10-15。不是实时、全量的欧洲职位库。中文概述与标签由本项目整理，所有岗位均链接原帖；薪资只列官方税前信息或基数，不估算到手收入。可导入自己核验的 JSON 岗位快照。

对标网站只用于理解功能和交互，不抓取、镜像、转载其岗位库、页面、付费报告或品牌。

## 运行与隐私

`python3 server.py`，打开 `http://127.0.0.1:8907/`；也可直接使用在线静态版。各人数据留在各自浏览器中，但没有加密、账号同步或共享团队库。同一浏览器配置／网址会共享存储，不同网址或端口不互通。请在申请清单中导出并私密保存备份。

没有带入任何原申请者的论文、CV、联系人、邮箱或申请记录；不自动发邮件、不自动投递。40 项 JavaScript 测试、8 项服务器测试通过。仍是有限数据、有限匹配能力的早期版本，不宣称已经达到参考站的全量采集与运营能力。
