# 申请面板 · Application Board

把原来个人申请系统的“岗位—材料—进度”思路整理成通用工具。每个人可以下载源码，在自己电脑运行并使用自己的空白工作区；不包含原申请者的 CV、邮箱、联系人、论文或申请记录。

运行 `python3 server.py`，打开 `http://127.0.0.1:8907/`。支持新增编辑岗位、搜索和阶段/国家筛选、日期提醒、材料准备清单、手动阶段更新、本地记录，以及 JSON 备份导入导出、CSV 导出。示例完全虚构，不是真实岗位推荐。

也可以直接打开 [在线静态版](https://olivia-wr-research.github.io/apps/application-board/)，不安装服务器。不同访客使用同一个页面，但数据各存在自己的浏览器，不共享申请库；托管方会收到正常的页面资源请求，应用本身不上传申请记录。本地版与在线版的浏览器存储不互通，需要手动导出再导入备份。

第一版是浏览器本地工具，**不是多人在线 SaaS**。同一个浏览器配置和网址会共享同一工作区；换电脑、浏览器、端口或主机名不会自动同步。数据未加密，清理浏览器数据可能丢失记录。请定期导出并私密保存备份。

不上传材料文件、不接入邮箱、不储存密码、不自动投递，也不会代替你核验截止日期、资助或申请资格。“已提交”只是你手动记录的状态。详情及测试命令见英文首页。
