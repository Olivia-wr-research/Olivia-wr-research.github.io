# 下一站 NextPosition · 0.7 岗位详情版

本次补充：双语标题同时显示、截止倒计时、国家与学科数量、来源与资助类型筛选、详情关键信息表及详情内收藏。倒计时按 UTC 日历日期计算，准确时点以原帖当地时间为准；筛选数量为目录总数，不是当前其它筛选条件下的数量。岗位数仍为 75，没有用新界面冒充数据扩容。研究组产出和毕业去向尚未上线，本科可申与英语即可标签尚未完成来源核验。

[直接使用](https://olivia-wr-research.github.io/apps/application-board/) · [本次更新与能力边界](docs/RELEASE_06.md)

不用先定义研究兴趣。你可以直接浏览、从课程与方法勾选线索、用简历提取待确认标签，或先了解研究单位。

- 75 条官方招聘公告、5 个国家，整理日期 2026-10-16。一条公告含两个名额仍计作一条，不是实时全量库。新增来源集中在瑞士、挪威，未知截止日期不代表仍在招聘。
- 发现页支持中英文切换，岗位标题、研究摘要和要求双语阅读，每次加载 20 条。
- ETH 与奥斯陆大学官方来源导入脚本先生成待审数据，完成去重和校验后再发布；尚未自动定时更新。
- 文字版 PDF / DOCX / TXT / Markdown 本机读取，或粘贴文本；不发送原文给服务器或模型。PDF 最多 20 页、文件最大 5 MB；扫描件需先本机 OCR。
- 提取只用固定词表，经历不等于兴趣或能力。须由你确认标签，不推断学历、英语或申请资格。
- 6 个研究单位证据入口，区分研究所、研究组和项目。毕业人数、去向、经费持续性与导师质量尚未核验，不编造体检分。
- 最多 3 条岗位并排对比，收藏连接原有材料与进度面板。还有 5 个官方来源入口，用于扩大自主检索。

匹配仍是透明关键词重合排序，不是语义模型或录取概率。页面分开提示待补充与需关注项，完整专业、语言、流动规则和合同以原帖为准。

`python3 server.py` 启动本机版；`node --test tests/*.test.mjs` 和 `python3 -m unittest discover -s tests -v` 运行检查。当前 81 项 JavaScript 与 23 项 Python 测试通过。DOCX 解压依赖现代浏览器原生能力，不支持时会要求 TXT 或粘贴；尚未完成真实手机与跨浏览器全矩阵验证。

只有已确认的概括标签和申请清单保存在当前浏览器，未加密、无跨设备同步。简历原文提取后或关闭表单时清空，不进入本地存储或 GitHub。请在申请清单导出并私密保存备份。同源脚本和共享浏览器仍在信任边界内。

不收集或公开原作者个人材料、论文、联系人或申请记录；没有复制参考站数据库、付费报告或代码。没有真人试用、用户增长或准确率的虚构结论。
