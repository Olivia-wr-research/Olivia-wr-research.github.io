# 履历证据处理工具

将本地文档解析为带原文和定位信息的履历事件；由使用者明确检查并填写机构 ID 后，再生成候选任职段与候选机构流动。它是离线命令行工具与 Python 库，不是自动核验人物履历的 AI Agent。

安装、完整运行命令和文件格式见 [英文首页](README.md)。示例人物、机构和经历全部虚构；示例含 5 个事件、5 个候选任职段和 2 次候选机构流动。访问角色不作为主要流动；`Present` 不会被填成当前年份。

支持的规则输入很有限：英文职位和年份范围、大写机构标题。TXT、简单 HTML、DOCX 无第三方运行依赖；PDF 需额外安装 pypdf，复杂版式和扫描件未验证。来源定位和固定规则分数不等于事实核验，机构同名不自动合并，未知信息不自动补齐。

所有运行只读取本地文件，不联网、不调用模型、不发送资料。输出包含输入原文和履历信息，必须留在本地；不要将真实运行目录上传 GitHub。公开版排除了真实人物材料、网页快照、科研数据、历史输出和未接通的网页界面。

这是从已有项目中整理的可复现公开子集，不包含原项目的全部能力，也不继承原项目的测试数量或科学结论。
