# Source and Access Quality

## Separate discovery from evidence

A source can be excellent for discovering papers but insufficient for supporting a specific claim.

### Discovery-grade examples
- search engine result pages;
- OpenAlex/Semantic Scholar metadata;
- citation lists;
- bibliographic records;
- repository landing pages.

### Evidence-grade preference order
1. full publisher or repository article text;
2. author-accepted manuscript / official preprint if version status is clear;
3. article abstract for claims explicitly contained in the abstract;
4. metadata only for bibliographic facts.

## Database honesty

Never state that a database was searched unless the current workflow actually queried that database or an authorized connector/API. If only a web search surfaced a Scopus-indexed paper, that is not a Scopus search.

## Quality dimensions to record separately

Do not collapse into one opaque score. Consider:

- venue/review status;
- relevance to the exact question;
- access completeness;
- design/inferential strength;
- sample/context appropriateness;
- measurement quality;
- replication/robustness;
- citation/field centrality when relevant;
- recency for rapidly changing topics.
