# Search Strategy Playbook

## 1. Decompose the question into concept families

Typical families:

- population/entity;
- focal phenomenon/outcome;
- antecedent/intervention/context;
- theoretical/mechanism concepts;
- geography/time where essential;
- synonyms, historical terms, disciplinary aliases.

Do not place every family into one query if it destroys recall.

## 2. Build query tiers

- **Tier A Precision**: exact focal concepts.
- **Tier B Recall**: synonyms and adjacent terminology.
- **Tier C Theory**: mechanism/theory-specific queries.
- **Tier D Citation chasing**: foundational and citing papers.
- **Tier E Contradiction**: null effects, critiques, failures, alternative explanations.

## 3. Log actual searches

For every search record:

- date;
- source/database/tool actually used;
- exact query;
- filters;
- result count if available;
- screened count;
- candidate IDs;
- notes.

## 4. Snowballing

Backward citation chasing locates foundations and measures. Forward chasing locates extensions, replications, critiques, and newer applications.

## 5. Saturation / stopping rule

Possible defensible stopping rules:

- two consecutive query expansions produce no new high-relevance concept/theory cluster;
- forward/backward chasing around core papers produces only duplicates or out-of-scope items;
- predefined database/query protocol completed plus targeted gap searches completed;
- additional sources no longer alter the theory/mechanism/method map.

Record which stopping rule was used.
