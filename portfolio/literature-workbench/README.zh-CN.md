# 文献与理论工作台

这是一个项目级 Agent/Skills 工作流工具包，不是独立网页应用，也不是自动写综述的服务。它包含 11 个 Skills、8 个角色配置、证据与论点模板，以及本地项目创建和检查脚本。

主要价值是将检索、筛选、原文提取、理论和方法比较、机制综合、框架构建、引文审计与写作分开，保留来源定位、矛盾证据，以及“作者主张”和“分析者解释”的区别。

无需模型即可运行 [英文首页](README.md) 的离线示例。启用 Agent 工作流则依赖兼容客户端、已配置模型与可用工具。并行角色只是配置，不代表已经完成论文阅读，也不构成只读安全沙箱。

公开版不包含真实研究题目、私有论文、阅读笔记或历史项目。只有明确虚构的 CSV 示例；它展示检查器如何处理证据等级，不代表任何真实文献结论。工作台脚本通过测试也不等于引文或科研判断正确。
