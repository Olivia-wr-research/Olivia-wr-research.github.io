# Theoretical Framework Builder

## Preconditions

Prefer a populated evidence matrix plus theory/mechanism outputs. If they are missing, state that the framework is provisional.

## Workflow

1. Read `references/framework-quality.md` and `references/theory-vs-mechanism.md`.
2. Define the focal explanandum and level(s) of analysis.
3. Define constructs precisely; merge synonyms and separate distinct constructs.
4. Build only necessary causal arrows.
5. For every arrow state the mechanism and temporal logic.
6. Add boundary conditions only with theoretical justification.
7. Add at least one credible rival explanation or alternative mechanism.
8. Separate literature-supported components (E0–E2) from new proposed components (E4).
9. Derive propositions/hypotheses that discriminate among mechanisms when possible.
10. Complete `08_framework/framework_canvas.md`.
11. Ask `skeptical_reviewer` to attack the framework before treating it as final.

## Quality test

The framework should explain more than a taxonomy, make fewer but stronger claims, and connect in principle to observable empirical tests.
