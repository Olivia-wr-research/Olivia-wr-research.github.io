# Theory Mapping

## Workflow

1. Read `references/theory-vs-mechanism.md`.
2. Use the evidence matrix as the primary source; reopen original papers for disputed or high-stakes theory claims.
3. For each theory populate `05_theory/theory_matrix.csv`.
4. Identify aliases and avoid splitting one construct into multiple labels without evidence.
5. Record level of analysis and focal explanandum.
6. Reconstruct causal logic, assumptions, predictions, and boundary conditions.
7. Distinguish deep theory use from citation decoration.
8. Identify competing/complementary theories and empirical discriminators.
9. Map where theory and operationalization diverge.
10. Preserve papers that contradict the dominant theory cluster.

## Output

Produce a theory map organized by explanatory problem, not by alphabetical theory names. State which elements are E0/E1 source-attributed and which are E2/E3 synthesis.
