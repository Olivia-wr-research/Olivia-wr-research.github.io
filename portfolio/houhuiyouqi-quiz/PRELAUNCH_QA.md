## 3. 算法与人格解释

- 趣味游戏五个自定义维度与每题四个选项的权重；固定规则、可复现。
- 随机生成 **50,000** 组答案做覆盖检验，八类均出现，模拟结果数范围约 4,056–8,939。这只是程序属性，不是实际用户比例。
- 检查：所有题为四选一、所有选项权重长度5、每题四组选项权重不相同。
- 结果是原创节目人物原型，不代表演员真实性格，也不构成心理测量；应在公开版本显眼标注。
- **下一步可做**：招募5–10名节目观众完成任务，问“结果最像自己的哪一段/最不准确哪一段”，并记录结果类型与偏离原因；根据反馈调整人物画像，不应随意调到「看起来平均」。

## 6. 美化技术选择

这套网站是静态原生HTML/CSS/JavaScript。无需为了“高级感”硬塞大型React UI库或滚动特效库：
- 使用 CSS 轻量转场、focus-visible 与 prefers-reduced-motion；
- React/Motion 等框架在需要组件化或复杂动画时很合适，但此版本单页规模不值得为了视觉效果整体重构；
- 保留独立的数据规则、模板和CI验收，防止视觉修改破坏实际答题、照片上传与图片导出。
